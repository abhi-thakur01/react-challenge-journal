# React Challenge Journal

A modern **Daily Learning Journal** for tracking a 90 Days React Challenge (or any learning challenge).

Built with **React + Vite + Tailwind CSS**.

## Features

- Dashboard with challenge progress, streak, study hours
- Daily journal (create / edit / delete entries)
- Topics knowledge base
- Project tracker with screenshots
- Goals, Resources, Weekly reflections
- Progress analytics + activity calendar
- Global search across everything
- Dark mode
- Export / Import JSON backup + Markdown export
- LocalStorage persistence (no backend needed)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build for production

```bash
npm run build
npm run preview
```

## Deploy (free)

- **Vercel:** import this repo → Framework: Vite → Deploy
- **Netlify:** import repo → build command `npm run build` → publish `dist`

## Stack

- React 18
- React Router v6
- Tailwind CSS
- Lucide React icons
- Vite
